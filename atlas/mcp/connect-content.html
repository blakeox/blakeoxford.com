Connect your AI to the Atlas

Ask about election results, voting blocs, or economic context and trace the answer back to the data.

Remote MCP endpoint

https://atlas.blakeoxford.com/mcp

In an MCP-capable client, add a remote server named Blake Oxford Election Atlas, choose Streamable HTTP, and paste the endpoint above. No Atlas API key or login is required. Your client must support public remote MCP servers; some plans or workspaces restrict adding them.

Example JSON configuration
{
  "mcpServers": {
    "blakeoxford-election-atlas": {
      "type": "http",
      "url": "https://atlas.blakeoxford.com/mcp"
    }
  }
}

Configuration fields vary by client. Use the URL directly if your client has an add-server screen.

Questions to try

  • Where did Milei have his highest runoff vote share in 2023? Show both the share and the vote count.
  • Compare Mexico and the Dominican Republic’s 2024 presidential results, with the vote-share denominators and sources.
  • What were the top party tallies in an El Salvador constituency, and what does the coverage include?
  • Compare Argentina and Brazil’s 2023 GDP per person and sector mix. Cite the World Bank indicators.

What you can query

Coverage spans 23 countries in South and Central America, Mexico, and the Latin Caribbean. Ask about national presidential rounds, historical ideological bloc trends, lower-house constituencies, Argentina’s 2023 province, section and circuit results, and economic, demographic, fiscal and geographic context where published. The tools return structured data with source links and notes.

Read-only. The connector exposes existing public Atlas data and does not run a model on the site. It is a historical snapshot, not a live results feed. Coverage varies by place; constituencies are not street blocks, and census demographics do not tell us how particular groups voted.
