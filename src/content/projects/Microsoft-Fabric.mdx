Built the operational backbone for a 200-person healthcare organization—uniting workflows, performance tracking, and automation across 10+ departments using Microsoft Fabric and Power Platform.

## 🔍 Project Overview

What began as a simple audit meeting quickly evolved into a full-scale operational transformation. I led a cross-functional initiative to map undocumented workflows, bridge gaps between departments, and build a real-time operational intelligence platform using Microsoft Fabric, Power BI, and the Power Platform.

By the end of the project, we had deployed performance dashboards across 10+ departments, automated critical task workflows in Microsoft Dynamics CRM, and began integrating quarterly goals through Microsoft Goals to align with the Entrepreneurial Operating System (EOS).

## 👔 Leadership Highlights

- Directed multi-department transformation strategy across ABA, PT, OT, Speech, Sales, Intake, Billing, Admin, Medical, and Compliance
- Conducted stakeholder interviews and BPMN process mapping to uncover undocumented workflows
- Facilitated change management across 200 staff and patients, prioritizing quality-of-care outcomes
- Led strategic planning sessions to align department KPIs with EOS Rocks and company-wide goals

## 🛠️ Technical Execution

- Built an Azure SQL staging layer using ODBC from our Practice Management System
- Developed Dataflow Gen2 pipelines in Microsoft Fabric for scalable data transformation
- Implemented SQL + Python logic for task audits, note quality checks, and KPI tracking
- Created Power BI dashboards with views tailored to staff, team leads, and executives
- Connected Power Platform workflows to Microsoft Dynamics CRM to automate patient lifecycle tasks
- Expanded the framework to cover PT, OT, and Speech along with indirect support across 10+ departments
- Initiated integration with Sage Intacct for financial forecasting and cash flow modeling

## 🧱 Architecture Overview

- **Source**: Practice Management System (ODBC → Azure SQL)
- **Transformation & Storage**: Microsoft Fabric + OneLake (Delta format)
- **Audit & Logic Layer**: SQL + Python
- **BI & Workflow**: Power BI, Power Automate, Power Apps, Microsoft Dynamics
- **ERP Integration Planning**: Sage Intacct

## 🔄 Project Lifecycle

1. Stakeholder Discovery & Workflow Mapping
2. BPMN Swim Lane Analysis
3. Data Infrastructure Build
4. KPI Dashboards & Note Auditing
5. CRM Task Automation via Power Platform
6. EOS Goal Integration (Microsoft Goals – in progress)
7. ERP Financial Forecasting Planning (Sage Intacct)

## 📈 Results

- 95% faster reporting cycles
- 60% reduction in manual oversight and status check-ins
- Automated lifecycle task workflows from patient scheduling through billing
- Performance dashboards live across 10+ departments
- Foundation built for EOS goal alignment and financial modeling

## ⚙️ Adoption & Change Management

The most complex challenge wasn't building the system—it was getting 200 people to use it.

We:

- Trained and onboarded cross-functional staff through walkthroughs and 1:1 support
- Communicated around improved care quality, not just system upgrades
- Earned buy-in by making teams more efficient and less reliant on memory or spreadsheets
- Made data visible and valuable to the people doing the work—not just leadership

## 🔮 What's Next

- Prototyped crosswalks from KPIs to long-term strategic outcomes
- Begun mapping Sage Intacct data into Fabric to bridge clinical ops with cash flow forecasting
