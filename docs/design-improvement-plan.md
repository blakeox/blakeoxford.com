## Direction and scope

Keep the ink, cool paper, copper, Space Grotesk, and Source Sans identity. Build an editorial portfolio around identity → evidence → work → writing → conversation. Photography should establish context; interface elements should explain their purpose without motion. Keep existing Astro components, semantic tokens, and progressive enhancement. No new services, fonts, packages, or generated imagery are required.

Systems touched: local Astro pages, shared CSS/recipes, component documentation, and browser tests. No customer data, credentials, account roles, approvals, or provider configuration change. Deployment remains a separate release gate. All design changes are reversible through the patch; preserve unrelated staged CORS work. Preserve duplicate copies in an external recoverable archive before removing them from the build input.
